## Commands

Run from `genai-usecases/content-moderation-system/`.

| Produces | Command | Time |
|---|---|---|
| Mock data | `backend/.venv/Scripts/python.exe recommendation/mock_data/generate_mock_data.py` | seconds |
| R1, R2, R3 | `backend/.venv/Scripts/python.exe recommendation/evaluation/run_gate_report.py` | about 1 minute |
| R4, R13 | `backend/.venv/Scripts/python.exe -m pytest recommendation/tests -q` | about 4 minutes |
| R5 to R10 and the six charts | `backend/.venv/Scripts/python.exe recommendation/evaluation/run_evaluation.py` | about 4 minutes |
| R12 | `backend/.venv/Scripts/python.exe recommendation/evaluation/run_live_demo.py` | a few minutes |
| One case by hand | `backend/.venv/Scripts/python.exe recommendation/evaluation/check_case.py --help` | instant |
| Host project's own tests | `cd backend && .venv/Scripts/python.exe -m pytest tests/ -q` | seconds |

R11 (the adversarial reviews) is not reproducible by command: it was three sessions of an
independent reviewer attacking the code. The findings and fixes are recorded in
`recommendation/results/RESULTS.md`, and each has a regression test.

## Checking determinism

```
cp recommendation/results/evaluation_metrics.json /tmp/first.json
backend/.venv/Scripts/python.exe recommendation/evaluation/run_evaluation.py > /dev/null
cmp /tmp/first.json recommendation/results/evaluation_metrics.json && echo identical
```

The metrics file was byte-identical across runs, including after later bug fixes.

## Which test backs which statement

| Statement | Test |
|---|---|
| No above-tier item in any feed, whatever the personalization state | `test_rec_feed_service.py::test_no_leak_through_the_full_feed_path_whatever_the_personalization_state` |
| Gate decisions do not depend on interests or learned signals | `test_rec_gate_invariants.py::test_gate_decision_is_independent_of_personalization_inputs` |
| A missing or malformed signal never lowers the rating | `test_rec_rating.py::test_deleting_any_signal_never_rates_below_adult`, `::test_malformed_signal_never_rates_below_adult` |
| Lower trust never sees more | `test_rec_mock_data.py::test_lower_trust_never_sees_more` |
| Parental controls never widen | `test_rec_mock_data.py::test_parental_controls_never_widen_except_the_sensitive_allowance` |
| A child's engagement cannot add a topic | `test_rec_personalization.py::test_child_engagement_can_never_add_a_topic` |
| High-risk items go first regardless of learned priority | `test_rec_queue_feedback.py::test_escalation_categories_jump_the_queue_regardless_of_learned_priority` |
| Each adversarial-review finding stays fixed | `test_rec_final_review.py` |

## If you rerun and get different numbers

Numbers depend on the code version. Bug fixes after the first evaluation did not change
any reported metric, but future changes might. Record the commit hash with every table,
and re-copy `recommendation/results/` into `data/` and `figures/` after a rerun.
